Privacidade e termos de uso

Versão 2026-11-25

Resumo

  • Você pode usar o Radar sem cadastro. Nesse caso, nenhum dado pessoal é coletado por nós.
  • Os prazos mostrados são estimados automaticamente. Confira sempre o edital original.

Quem é o responsável

O cadastro ainda não está disponível. Enquanto isso, o Radar não coleta dados pessoais.

Uso sem cadastro

  • Os filtros, a ordenação e a escolha de dispensar o convite de instalação ficam guardados só no seu aparelho (armazenamento local do navegador). Não são enviados a ninguém. Para apagar, limpe os dados do site no navegador.
  • O aplicativo guarda uma cópia das páginas e das oportunidades no aparelho para funcionar sem internet.
  • O site é hospedado pelo GitHub Pages, que registra dados técnicos de acesso (como o endereço IP) para segurança e funcionamento, conforme a declaração de privacidade do GitHub.
  • Ao abrir um edital, você vai para o site do órgão que o publicou, que tem as próprias regras de privacidade.

Termos de uso

  • O Radar reúne automaticamente links para editais, bolsas, seleções, eventos e vagas publicados por terceiros. Não somos responsáveis pelos editais nem pelas seleções.
  • Prazos, áreas e tipos são estimados por um programa e podem estar errados ou desatualizados. Antes de qualquer decisão, confira o edital original no site do órgão.
  • O serviço é gratuito, oferecido como está, e pode mudar ou sair do ar sem aviso.

Mudanças neste documento

Quando este texto mudar, a versão acima também muda. Se você tiver conta, pediremos que aceite a nova versão na próxima vez que entrar.
